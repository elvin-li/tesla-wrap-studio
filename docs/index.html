怎么用 GitHub

一张图，变成你的特斯拉车衣

拖进图片，自动贴满整辆车，还能把脸放上车头。全部 12 个官方车型。自带免费 AI 生图。

1选车型

2放图片

没图？试试：
AI 生图免费，不用注册
灵感：

免费：大约每 45 秒一张。你写的文字会发给 Pollinations。找脸在你的浏览器里完成。

接口设置

支持 OpenAI 格式的接口（OpenAI、硅基流动、自建代理等）。Key 只存在这台电脑的浏览器里。用 AI 时，你的文字和图片会发给你填的接口，会按它的价格扣费。

3选风格

点图片里的脸，车头就换成它。红框 = 车头，蓝框 = 车门。

4微调

先放一张图片

.png

    放进车里

    1. 01

      建文件夹

      U 盘（exFAT / FAT32）根目录建一个 Wraps 文件夹。

    2. 02

      拷进去

      把下载的 PNG 放进去。一次最多 10 张。

    3. 03

      插车上

      玩具箱 → 涂装店 → 贴膜，选你的图。

    4. 04

      或用手机

      特斯拉 App 4.59+：创作 → 贴膜 → 上传。
