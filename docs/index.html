Wrap Studio
怎么用 GitHub

一张图，变成你的特斯拉车衣

拖进图片，自动贴满整辆车。全部 12 个官方车型，图片只在你的浏览器里处理。

1选车型

2放图片

没图？试试：

3选风格

4微调

先放一张图片

.png

    放进车里

    1. 01

      建文件夹

      U 盘（exFAT / FAT32）根目录建一个 Wraps 文件夹。

    2. 02

      拷进去

      把下载的 PNG 放进去。一次最多 10 张。

    3. 03

      插车上

      玩具箱 → 涂装店 → 贴膜，选你的图。

    4. 04

      或用手机

      特斯拉 App 4.59+：创作 → 贴膜 → 上传。

    模板来自特斯拉官方仓库 teslamotors/custom-wraps。本项目与特斯拉无关。请只用你有权使用的图片。
